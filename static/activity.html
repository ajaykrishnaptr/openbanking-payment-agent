Payment agent

TrueLayer sandbox · test money only

Every decision this agent has made.

One row per completed run, written once and never changed. It records what the payee check returned and which provider produced it, whether the consent was valid, what the risk rules flagged, who decided, and which payment came out the other end.

This is a separate record from the checkpoints that let a paused run resume. Those exist to restart work and their shape belongs to the framework. This table exists to answer questions afterwards, so it is indexed by payee, amount and date, and it stores only the last 4 digits of an account number.
