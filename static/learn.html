The concepts this agent runs on.

LangGraph gives you a state machine with a checkpointer. That is most of what an agent handling money needs, and almost none of what people mean when they say agent. Below are the parts this one actually uses.

Every excerpt is read out of the running deployment and located by parsing the file, so the code here is the code that ran. Nothing is pasted. Concepts this repository does not demonstrate are left out rather than described.

  1. Reading the source…

A payments flow is a deliberately small corner of the framework: it runs once, forwards, and stops. Cycles, dynamic fan-out with Send, subgraphs and rewinding a thread with get_state_history are all real LangGraph, and none of them appear here because this agent does not use them.
